Your products

When you have finished

Press Save everything at the bottom. Your browser will download a file called products-data.js, plus a photo file for each new picture you added.

  1. Go to your repository on github.com.
  2. Click Add file → Upload files.
  3. Drag in products-data.js. It replaces the old one.
  4. If you added photos, open the images folder first, then the products folder inside it, and upload them there.
  5. Click Commit changes. The website updates within a minute.
